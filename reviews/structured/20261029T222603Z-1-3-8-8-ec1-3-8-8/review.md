### F2: Imported protein pointers are labeled curator-picked

minor / open / confirmed; issue key: ec-1-3-8-8-imported-example-provenance.

All stored examples are labeled CURATOR while their notes explicitly record an ExPASy ENZYME DR import. The current seeder and schema distinguish imported selection from curator-picked selection; experimental qualification does not change selection origin.

### F3: ETF flavin cofactors are typed as residues

minor / open / confirmed; issue key: ec-1-3-8-8-etf-cofactor-node-type.

The stored RESIDUE nodes denote FAD/FADH2 chemical forms within generic ETF. A numbered reactive-part slot is not an amino-acid sequence residue. Exact chemical identities, multiplicity and constituent relations remain supported.

### F4: Source line wrapping splits a chemical token

minor / open / confirmed; issue key: ec-1-3-8-8-source-linewrap-token.

The top-level definition, MECHANISTIC text and quoted graph equation contain 'electron- transfer'. Current normalized reaction objects and the correctly named graph participants use 'electron-transfer'. This is a source-folding typography issue, not a different chemical identity.
