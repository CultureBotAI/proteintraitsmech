# Goal

The whole workflow lives in **[`prompts/goal.md`](../../../prompts/goal.md)** — read
that file and follow it. This skill exists only so `/goal` resolves; a document under
`prompts/` is not a slash command on its own.

Keeping the content in `prompts/` rather than here puts it beside
`prompts/schema-review.md`, where the repo's other hand-over prompts live, and lets it
be pasted to an independent reviewer or another agent without dragging the skill
wrapper along.

**Do not edit this file to change behaviour** — edit `prompts/goal.md`. Two copies of
a procedure diverge; that has already happened six times in this repo with parsing
helpers, and it is the reason `scripts/obo_syntax.py` and `scripts/record_io.py` exist.

If the user passed an argument (`/goal #104`, `/goal tests`), treat it as the hint for
step 1's selection and skip the ranking pause when it names a specific issue.
